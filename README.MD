# PERSONAL PORTFOLIO WEBSITE

## Deskripsi
Website portofolio pribadi yang dibuat untuk
memperkenalkan profil, kemampuan, proyek,
dan informasi kontak.

## Teknologi
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Fitur
1. Responsive Navigation
2. About Me
3. Skills Progress Bar
4. Project Filter
5. Project Detail Modal
6. Dark Mode dan Light Mode
7. Contact Form Validation
8. Back To Top
